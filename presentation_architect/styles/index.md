# Presentation Styles Catalog

This registry contains all available presentation styles. When a user requests a presentation, you **MUST** select one of these styles.

### How to Use a Style:
1. Review the list of available styles below.
2. Select the style that best matches the presentation's topic, target audience, and mood.
3. Read the corresponding `styles/[name].md` file to understand its specific layout system (e.g. `BW01`, `S01`) and typographic constraints.
4. **CRITICAL:** You must strictly follow the layout names and rules defined in the style's `.md` file when drafting your `_blueprint.yaml`.

---

## Available Styles

- **`swiss-simple`**: Clean, analytical Swiss aesthetic featuring massive thin typography, blue accents, hairline dividers, and stark data visualizations. Perfect for consulting and engineering pitches. ([Read Guidelines](styles/swiss-simple.md))
- **`business-wireframe`**: High-contrast, professional corporate presentations characterized by wireframe stroke cards, sharp top dividers, and disciplined geometric grids. Best for B2B pitches, technical deep-dives, and corporate training. ([Read Guidelines](styles/business-wireframe.md))
- **`floating-cards`**: Warm, friendly, modern SaaS, educational, or highly detailed aesthetic with depth, floating elements, and gentle shadows. ([Read Guidelines](styles/floating-cards.md))
- **`magazine`**: Editorial, humanistic, "Monocle magazine", or e-ink style. Features serif headers, fluid minimal backgrounds, and strict grid alignments for photos. ([Read Guidelines](styles/magazine.md))
- **`swiss`**: Swiss Typographic Style designs. Features massive typography, absolute grid alignment, high contrast, and minimalist aesthetics. ([Read Guidelines](styles/swiss.md))
- **`vscode-ide`**: Highly geeky, developer-centric presentation style that mimics the Visual Studio Code interface. Features syntax highlighting, Mac terminal windows, and iMessage chat bubbles. Best for technical pitches, engineering teams, and software architecture overviews. ([Read Guidelines](styles/vscode-ide.md))
